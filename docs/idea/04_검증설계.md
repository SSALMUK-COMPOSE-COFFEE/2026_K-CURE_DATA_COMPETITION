# 04. 검증 설계

> 1차 배점 **"분석 결과를 평가하고 검증하는 방법론 제시 여부 15점"** 을 정면으로 겨냥합니다.
> 대부분의 참가팀이 이 항목을 비워 두므로, 여기서 순위가 갈립니다.
> 보고는 **TRIPOD+AI** 보고 지침을 따릅니다.

## 1. 데이터 분할 — 시간분할 외부검증

| 구분 | 진단연도 | 역할 |
|---|---|---|
| 학습 | **2014 ~ 2017** | 모델 적합, 하이퍼파라미터 튜닝 |
| 검증 | **2018 ~ 2019** | 최종 성능 평가 (한 번만 사용) |

- 무작위 분할이 아닌 **시간분할**을 쓰는 이유: 실제 활용 상황은 "과거로 학습해 미래 데이터에 적용"이며, 치료 관행 변화(면역항암제 급여 확대 등)에 대한 **모델 드리프트를 함께 평가**할 수 있습니다. Finn 2023도 동일한 설계(2014–16 학습 / 2017 검증).
- 학습셋 내부에서는 **5-fold 교차검증**으로 하이퍼파라미터를 정합니다.
- 검증셋은 **최종 1회만** 사용합니다(계획서에 명시 → 사후 선택 방지 신호).

## 2. 성능 지표

### 주 지표
**다중분류 Scaled Brier Score (SBS)** — 예측 확률의 정확도와 보정도를 동시에 반영. Finn 2023의 주 지표와 동일해 국제 비교가 가능합니다.

### 보조 지표 (클래스별)

| 지표 | 의미 |
|---|---|
| C-statistic (one-vs-rest AUROC) | 판별력 |
| 민감도 / 특이도 / PPV / NPV | 운영 관점 성능 |
| Macro-F1, balanced accuracy | 클래스 불균형 보정 |
| 전체 정확도 | 선행연구 비교용 (NSCLC 77.5% 기준선) |

### 참조 성능 (선행연구 기준선)

| 선행연구 | 성능 |
|---|---|
| NSCLC, Medicare claims (ISPOR 2023) | 정확도 **77.5%** |
| 대장암, Finn 2023 | Stage IV C-stat 0.95(민감도 93%) / I–II 0.88(86%) / **III 0.82(62%)** |

→ **"국소진행(III)이 가장 어렵다"는 것이 이미 알려져 있습니다.** 우리 결과도 그럴 가능성이 높으므로, 이를 실패가 아니라 **재현된 알려진 현상**으로 해석하는 프레임을 미리 준비합니다.

## 3. 불확실성 추정

- **부트스트랩 1,000회** 재표본으로 모든 성능 지표의 95% 신뢰구간 산출
- 모델 간 비교는 신뢰구간 중첩 여부로 판단 (단일 점추정 비교 금지)

## 4. 보정도(calibration)

- **클래스별 보정 플롯** — 예측확률 십분위별 관측 비율
- **보정 기울기(calibration slope)와 절편**
- 다중분류이므로 one-vs-rest 방식으로 3개 플롯 제시

## 5. 해석성

- **SHAP 값** 기반 변수 중요도 (Finn 2023도 Shapley value 사용)
- 상위 20개 변수를 **임상 지식과 대조**: 수술·CCRT·전이 상병·완화의료가 기대 방향으로 기여하는지 확인
  → 방향이 반대인 변수가 있으면 데이터 처리 오류 탐지 장치가 됩니다
- 다항 로지스틱 회귀 계수표를 **전문(全文) 공개**(재현성)

## 6. 비교·대조 모델 (필수)

| 대조군 | 목적 |
|---|---|
| **규칙 기반 baseline** (C77–C79 전이 상병만으로 IV 판정) | 기존 관행 대비 개선 폭 정량화 |
| **Ablated model** (치료 변수 A그룹 전체 제외) | **"치료로 병기를 맞히는 순환논리" 반론 대응** |
| 다항 로지스틱 vs Elastic net vs 트리 앙상블 | 복잡도 대비 이득 확인 |

> Ablated model은 반드시 넣으세요. 심사에서 이 반론이 나왔을 때 **"미리 검증했습니다"** 라고 답할 수 있는지가 발표 점수를 가릅니다.

## 7. 하위군 형평성 평가 ⭐ 차별화 지점

모델이 **어떤 환자에서 틀리는가**를 체계적으로 봅니다. Finn 2023도 인종별 성능 차이를 보고했고, 의료 접근성이 낮은 집단에서 성능이 떨어짐을 확인했습니다.

| 하위군 축 | 변수 | 왜 중요한가 |
|---|---|---|
| **소득계층** | `BFC.CALC_CTRB_VTILE_FD` (의료급여 포함) | 치료 접근성이 낮으면 치료 신호가 약해 성능 저하 예상 |
| **요양기관 종별** | `T200.CL_CD` (상급종합 vs 그 외) | 진료 패턴 차이 |
| 연령 | `RGST.AGE` (특히 최고령군) | 고령자는 적극적 치료를 덜 받음 |
| 성별 | `RGST.SEX` | |
| **전신상태** | `RGST.ECOG` | 임상변수 — **피처로는 안 쓰고 평가에만 사용** |
| **조직형** | `RGST.H_NAME_1~7` | 편평상피 vs 선암 등 아형별 성능 |
| 지역 | `BFC.SIDO_CD` | 지역 간 의료 접근성 |

> ⭐ **이 설계의 묘수**: 임상변수(`ECOG`, `H_NAME_*`, `EGFR`)를 피처에서 배제하고 **평가 축으로만 쓰기** 때문에, "청구데이터만 쓴 모델"이라는 순수성을 지키면서 임상적으로 깊이 있는 평가가 가능합니다. 임상의 없는 팀이 임상적 타당성을 보여줄 수 있는 방법이기도 합니다.

**형평성 결과의 활용**: 특정 취약계층에서 성능이 낮다면 그것은 실패가 아니라 **"청구기반 병기 대리변수를 형평성 연구에 쓸 때의 주의사항"** 이라는 독립적 기여가 됩니다. 반드시 논의에 포함하세요.

## 8. 민감도 분석 (사전 명시)

| # | 변경 사항 | 목적 |
|---|---|---|
| S1 | look-forward 창 6개월 → 3개월 / 9개월 | 관찰 창 민감도 |
| S2 | index date 월 1일 → 15일 | `FDX` 월 단위 정밀도 한계 |
| S3 | 라벨을 임상병기 → **병리병기(`HP_*`)** | 라벨 정의 민감도 (수술군 한정) |
| S4 | 3분류 → **2분류(국한 vs 진행)** | 표본 부족 대비 + 성능 상한 확인 |
| S5 | 소세포폐암(`H_NAME_5`=1) 포함 모델 | 대상 정의 민감도 |
| S6 | 병기 결측(`99`) 환자 특성 비교 | 선택 편향 평가 |
| S7 | 진단 후 6개월 내 사망자 제외 | 관찰 창 절단 영향 |

## 9. 2단계 — 후속 활용 타당성 검증

1단계 모델이 좋다는 것과 **연구에 써도 된다**는 것은 다른 문제입니다. 정답 병기가 있는 이 데이터에서만 가능한 검증을 수행합니다.

### 절차
1. 검증셋(2018–2019 진단) 환자에 대해 예측 병기 산출
2. 소득계층별 전체 사망 위험비(HR)를 **세 가지 Cox 모형**으로 추정
   - (a) 병기 미보정 · (b) 예측 병기 보정 · (c) 실제 병기 보정
3. 편향 감소율 산출 및 부트스트랩 95% CI

```
편향 감소율 = 1 − |log HR_pred − log HR_true| / |log HR_naive − log HR_true|
```

### 보조 설계
- 예측 병기를 **최빈 클래스**로 넣는 방식과 **예측 확률(연속형)** 로 넣는 방식을 모두 시행 → 후자가 측정오차를 덜 유발할 가능성이 있음
- 비교 기준값: 선행연구의 의료급여 대비 최고소득군 폐암 사망 HR **1.56 (95% CI 1.51–1.59)** (KCCR–NHID 2014–2018, 폐암 n=109,116)
- 비례위험 가정 검정(Schoenfeld 잔차), 위배 시 시간분할 Cox

### 발표 슬라이드로서의 가치
세 개의 HR을 한 장의 forest plot으로 보이면, **"병기를 보정하지 않은 기존 청구 연구가 얼마나 치우쳐 있었는가"** 와 **"우리 모델이 그 치우침을 얼마나 되돌리는가"** 가 한 눈에 전달됩니다. 2차 배점 "연구결과 중요성 50점"을 겨냥한 핵심 장면입니다.
