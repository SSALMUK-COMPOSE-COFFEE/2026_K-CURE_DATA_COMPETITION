# 02. 연구 설계

## 전체 구조

```
[1단계] 병기 추정 모델 개발·검증
  라벨 : CS_LC_RGST 의 AJCC 8판 임상 T/N/M → 3분류(국한 / 국소진행 / 원격전이)
  피처 : 청구(T200·T300·T400·T530) + 자격(BFC) + 검진(G1E·G1Q) — 임상변수 미사용
  검증 : 진단연도 시간분할 (2014–2017 학습 / 2018–2019 검증)
                    ↓
[2단계] 후속 활용 타당성 검증 (downstream utility validation)
  소득분위별 사망 위험비를 세 방식으로 추정해 비교
    (a) 병기 미보정  (b) 예측 병기 보정  (c) 실제 병기 보정(정답)
  → 예측 병기가 실제 병기 보정 결과를 얼마나 복원하는가
```

## 1단계 상세

### 대상 코호트

```
CS_LC_RGST 전체 (2014~2019년 진단 폐암)                    N = ____
 └ 제외: 병기 라벨 결측 (HC_T_8TH=99 or HC_N=9 or HC_M_8TH=9)  N = ____
    └ 제외: 소세포폐암 (H_NAME_5 = 1)  → 별도 부수분석            N = ____
       └ 제외: 진단 전 12개월 청구 이력 없음(자격 미유지)          N = ____
          └ 최종 분석 대상 (비소세포폐암)                       N = ____
```

> 실제 N은 폐쇄망 입실 후 확정. 계획서에는 **국가암등록통계 기준 예상치**를 제시하고, N에 따른 대응책([05 문서](05_실행계획_리스크.md))을 함께 씁니다.

**index date 정의**: `FDX`(최초진단연월)는 **YYYYMM 월 단위**로만 제공됩니다.
→ 해당 월의 **1일**을 index date로 두고, 월 단위 정렬 오차(최대 ±30일)를 한계로 명시. 민감도 분석에서 15일 기준으로 재실행.

### 라벨 정의 — AJCC 8판 → 3분류

주 라벨은 **임상 병기**(`HC_T_8TH`, `HC_N`, `HC_M_8TH`)를 사용합니다.
병리 병기(`HP_*`)는 수술받은 환자에게만 존재하므로 그것을 라벨로 쓰면 **수술군 편중(selection bias)** 이 생깁니다. → `HP_*` 는 민감도 분석용.

| 클래스 | 정의 (AJCC 8판 비소세포폐암) | 대략적 stage |
|---|---|---|
| **3. 원격전이** | `HC_M_8TH` ∈ {1, 2, 3, 4} (M1a/M1b/M1c/M1 NOS) | IV |
| **2. 국소진행** | M0 이고 (`HC_N` ∈ {2,3} 또는 `HC_T_8TH`=11(T4) 또는 (`HC_T_8TH`=10(T3) 그리고 `HC_N`=1)) | III |
| **1. 국한** | 나머지 M0 (T1–T3, N0–N1) | I–II |

> 위 규칙은 AJCC 8판 병기군표에 따른 축약입니다. 폐쇄망 입실 후 **원본 병기군표와 대조 검증**하고, 매핑 코드를 산출물로 남깁니다.
> 3분류를 쓰는 이유: 임상적으로 **I–II = 수술 중심 / III = 동시항암화학방사선요법(CCRT) 중심 / IV = 전신치료 중심**으로 치료 전략이 갈려 청구 신호가 구분되며, 선행연구(Finn 2023)와 동일한 구조라 결과 비교가 가능하기 때문입니다.

### 피처
→ [03_피처설계.md](03_피처설계.md) 전체 참조

**절대 원칙: `CS_LC_RGST`의 임상변수(`SMOKE`, `ECOG`, `EGFR_MUTATION`, `ALK_*`, `H_NAME_*`, `HEIGHT`, `WEIGHT`)는 피처로 쓰지 않습니다.**
이 모델의 목적은 *"그 변수들이 없는 일반 청구데이터"* 에 병기를 부여하는 것이기 때문입니다. 이 변수들은 **하위군 성능 평가용**으로만 사용합니다(→ 오히려 강력한 검증 장치가 됩니다).

### 모델

| 순서 | 모델 | 역할 |
|---|---|---|
| 0 | **규칙 기반 baseline** — 전이 상병코드(C77/C78/C79) 유무만으로 IV 판정 | 기존 관행 대비 개선 폭 제시 |
| 1 | **다항 로지스틱 회귀** | 해석 가능한 기준 모델 |
| 2 | **Elastic net (정규화 다항 로지스틱)** | Finn 2023의 최종 채택 모델. 표본 대비 변수 많을 때 안정적 |
| 3 | **Gradient boosting / Random forest** | 비선형·상호작용 포착 |
| 4 | **Ablated model** (치료 변수 제외) | "순환논리" 반론 대응 |

**주 설계는 2번(elastic net) + 핵심 피처 40개 세트입니다.** 추정 표본이 약 10,000~12,000명(비소세포폐암·결측 제외 후)으로 Finn 2023의 필요 표본 21,750명의 절반 수준이기 때문입니다([03_피처설계.md](03_피처설계.md) 참조). 3번(트리 계열)과 확장 피처 세트는 **비교군**으로 함께 학습하되, 주 결과가 아닙니다.

모델 최종 선택은 **학습셋 5-fold 교차검증의 다중분류 Scaled Brier Score**로 하고, 선택 규칙을 계획서에 미리 명시합니다(사후 선택 방지). 검증셋은 최종 평가에 1회만 사용합니다.

폐쇄망 가용성을 고려해 **표준 패키지만** 사용:
- R: `glmnet`, `nnet`(multinom), `ranger`, `survival`, `riskRegression`
- Python: `scikit-learn`, `pandas`, `numpy`, `lifelines`
> GPU 불필요. 딥러닝 미사용(표 형태 데이터에서 이점이 없고, 폐쇄망 환경 리스크만 커짐).

## 2단계 상세 — 후속 활용 타당성 검증

### 목적
"예측 병기를 실제 연구의 교란 보정에 쓸 수 있는가"를 정량적으로 답합니다.

### 설계

- **대상**: 1단계 검증셋(2018–2019 진단) — 학습에 쓰이지 않은 환자
- **결과변수**: 전체 생존. `CS_LC_DEATH.DREGDATE`(사망연월일) 기준, 추적 종료 2022-12-31로 중도절단
- **노출변수**: `CS_LC_BFC.CALC_CTRB_VTILE_FD` (보험료 1~10분위, **0 = 의료급여수급권자**)
  → 선행연구와 비교 가능하도록 **의료급여 / 1–3분위(저) / 4–7분위(중) / 8–10분위(고)** 4범주로 축약
- **공변량**: `AGE`, `SEX`, `SIDO_CD`, 진단연도, Charlson 동반질환지수(청구 상병으로 산출), 요양기관 종별(`CL_CD`)

### 세 가지 Cox 모형

| 모형 | 병기 보정 방식 |
|---|---|
| (a) Naive | 병기 미보정 |
| (b) **Predicted** | 모델 예측 병기(최빈 클래스) 보정 · 추가로 예측 확률 3개를 연속형 공변량으로 넣는 방식도 병행 |
| (c) Gold | 실제 병기(`HC_*` 기반 라벨) 보정 |

### 주 성과지표

```
편향 감소율 = 1 − |log HR_pred − log HR_true| / |log HR_naive − log HR_true|
```

- 1에 가까울수록 예측 병기가 실제 병기를 잘 대체한 것
- 부트스트랩 1,000회로 95% 신뢰구간 산출
- 보조: HR 추정치 세 개를 forest plot 한 장으로 제시 → **발표 슬라이드의 핵심 장면**

### 왜 이 설계가 강한가
- 정답 병기가 있어야만 가능한 검증 → **이 데이터가 아니면 못 하는 분석**
- 결과가 어느 방향으로 나와도 의미가 있음
  - 편향이 크게 줄면 → 모델의 실사용 가치 입증
  - 잘 줄지 않으면 → "청구 기반 병기 대리변수의 한계"라는 방법론적 경고. **음성 결과도 발표 가치가 있어 리스크가 낮습니다.**

## 산출물 목록 (반출 대상)

폐쇄망 반출 심사를 통과해야 하므로, **개인단위 데이터가 아닌 집계 결과만** 산출하도록 미리 설계합니다.

1. 코호트 선정 플로우차트 (단계별 N)
2. Table 1 — 병기별 기본 특성
3. 모델별 성능표 (Scaled Brier, C-statistic, 민감도/PPV, 클래스별)
4. 다중분류 혼동행렬
5. 클래스별 보정도(calibration) 플롯
6. 변수 중요도 / SHAP 요약 플롯
7. 하위군 성능표 (보험료분위·기관종별·연령·성별·ECOG·조직형)
8. 2단계 forest plot 및 편향 감소율
9. 분석 코드 (재현성)

> 모든 표에서 **셀 빈도 N<5 는 마스킹**하도록 처리 함수를 미리 만들어 둡니다.
