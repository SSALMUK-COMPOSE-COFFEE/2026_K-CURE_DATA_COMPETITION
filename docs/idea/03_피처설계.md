# 03. 피처 설계

> 모든 변수는 **[데이터 카탈로그](../competition/데이터카탈로그/폐암_병기조사_카탈로그.txt) 실재 컬럼**입니다.
> 1차 배점 15점("데이터 카탈로그 내 변수 사용 여부")을 직접 겨냥합니다.

## 관찰 창(observation window)

```
      진단 전 12개월              진단월(FDX)            진단 후 6개월
 ├───────────────────────┼──────────────────┼──────────────────┤
   동반질환·검진·의료이용        index               치료 신호(핵심)
```

- **look-back 12개월**: 동반질환, 진단 전 의료이용, 검진 이력
- **look-forward 6개월**: 초기 치료 패턴 — 병기 신호의 대부분이 여기 있음
- 선행연구(Finn 2023)는 12개월 전 ~ 9개월 후를 사용. 우리는 **6개월**로 잡아 진행성 환자의 조기 사망에 의한 정보 절단(informative censoring)을 줄이고, 민감도 분석에서 3·9개월로 변경

> 청구 일자는 `T200.RECU_FR_DD`(요양개시일자, YYYYMMDD). `FDX`가 월 단위이므로 **월 기준 상대시점**으로 정렬합니다.

## 조인 구조

```
CS_LC_RGST ──(대상자 키)── CS_LC_BFC / CS_LC_DEATH / CS_LC_G1E / CS_LC_G1Q_*
                        └─ CS_LC_T200 ──(MID)── CS_LC_T300
                                       ──(MID)── CS_LC_T400
                                       ──(MID)── CS_LC_T530
```
`MID`(명세서조인키)로 청구 4개 테이블을 결합 → 대상자 단위로 집계.

## 피처 그룹

### A. 치료 — 병기 신호의 핵심 (진단 후 0~6개월)

| # | 피처 | 산출 방법 |
|---|---|---|
| A1 | 폐 수술 시행 여부 | `T200.SOPR_YN` = 2(수술) 이면서 `T200.M_SICK_CD` 가 C34* |
| A2 | 흉부외과 진료 | `T200.DGSBJT_CD` = 08(심장혈관흉부외과) 방문 건수 |
| A3 | 수술 관련 처치 강도 | `T300.CZ_ITEM_CD` 대분류 = **"처치 및 수술"** 항목의 건수·총액 |
| A4 | 수술까지 소요 개월 | 첫 수술 청구의 index 대비 상대 월 |
| A5 | 방사선치료 시행·강도 | `T300.CZ_ITEM_CD` = **"영상진단 및 방사선치료료"**, `T200.DGSBJT_CD` = 18(방사선종양학과) 방문 횟수 |
| A6 | 항암 주사 치료 | `T300.CZ_ITEM_CD` = **"주사료"** 중 항암 관련, `T300.GNL_CD`(일반명코드) 기반 성분 식별 |
| A7 | 항암제 성분군 | `GNL_CD` → 백금계(cisplatin/carboplatin), pemetrexed, taxane, **EGFR-TKI**, **ALK 억제제**, **면역관문억제제** 각각 이진 |
| A8 | 경구 항암제 | `T530.GNL_CD` + `T530.TOT_INJC_DDCNT_EXEC_FQ`(총투여일수) |
| A9 | **CCRT 패턴** | 진단 후 동일 30일 창 내 방사선 + 항암 동시 시행 여부 → **III기의 강한 신호** |
| A10 | 치료 순서 | 수술 우선 / 항암 우선 / 방사선 우선 / 무치료 (범주형) |
| A11 | **무치료** | 진단 후 6개월 내 수술·항암·방사선 모두 없음 → 초고령·말기 신호 |

> 💡 **약가코드는 카탈로그상 NULL로 가명처리되고 `GNL_CD`(일반명코드)로 제공**됩니다. 따라서 약제 식별은 반드시 `GNL_CD` 기준으로 설계해야 합니다. 진료행위코드(`DIV_CD`)는 전체 제공되므로 수술·방사선·검사는 코드로 식별 가능합니다.

## 예상 피처 수와 대응

위 설계를 전부 전개하면 **80~120개** 피처가 생성됩니다. 그러나 **이 확장 세트는 주 설계가 아닙니다.**

Finn 2023은 87개 예측변수에 대해 "최소 빈도 클래스 기준 예측변수당 50명"으로 약 **21,750명**을 필요 표본으로 산정했습니다. 반면 폐암 병기조사 DB의 추정 규모는 그 절반 이하입니다([05_실행계획_리스크.md](05_실행계획_리스크.md) 리스크 1 참조).

| 단계 | 추정 N |
|---|---|
| 병기조사 대상자 (2014~2019 진단, 연 10% 표본) | 약 16,000~17,000 |
| 비소세포폐암 한정 (약 79%) | 약 13,000 |
| 병기 라벨 결측·청구이력 결측 제외 후 | **약 10,000~12,000** |

→ Finn 기준의 **절반 수준**이고, 최소 빈도 클래스(국소진행 III기)를 기준으로 하면 여유가 더 줄어듭니다.

### 따라서 주 설계는 "핵심 40개 + elastic net"입니다

| 세트 | 피처 수 | 위치 |
|---|---|---|
| **핵심 세트 (주 설계)** | **약 40개** | 아래 선정 기준 참조 |
| 확장 세트 | 80~120개 | N이 예상보다 크거나(≥15,000), 핵심 세트가 과소적합일 때만 |

**핵심 40개 선정 기준** — 입실 전에 확정해 둡니다(입실 후 데이터를 보고 고르면 선택 편향).

1. **A그룹(치료) 전부** — 수술, 방사선, 항암제 성분군, CCRT 패턴, 무치료 여부. 병기 신호가 가장 강하고 Finn 논문에서도 상위 기여
2. **B그룹(전이) 전부** — C77/C78/C79 및 부위별, 뇌 MRI·PET-CT, 흉수 처치. 원격전이 판별의 핵심
3. **C그룹(진단검사) 상위** — 기관지내시경·EBUS, CT/MRI 건수
4. **D그룹(의료이용) 상위** — 입원일수, 응급실 경유, 요양기관 종별, 완화의료, 마약성 진통제
5. **E그룹(인구사회) 전부** — 연령·성별·보험료 분위·지역·Charlson (변수 수가 적고 교란 보정에 필수)
6. **F그룹(검진)은 핵심 세트에서 제외** — 수검자에게만 존재해 결측이 크고, 병기 신호는 약함. 확장 세트로만

### 그 외 대응

1. **Elastic net**으로 자동 변수 선택 (계수 축소) — 핵심 세트 위에서도 유지
2. 필요 시 **2분류 축약**(국한 vs 진행) — 췌장암 선행연구에서 정확도 65.9% → 88.5%로 회복된 전례
3. 확장 세트는 **민감도 분석**으로 보고 — "변수를 늘려도 개선이 없었다"는 것 자체가 검증 15점 재료

## 결측·이상치 처리 원칙

| 상황 | 처리 |
|---|---|
| 병기 라벨 `99`/`9`(모름) | 학습에서 제외. **제외군 특성을 Table로 보고**(선택 편향 평가) |
| 검진 변수 결측 | 결측 지시자 + 중앙값 대체 |
| 청구 이력 없음 | 자격 미유지로 간주해 코호트에서 제외 |
| `AGE` 5세 단위 | 범주형 그대로 사용 (연속형 가정 금지) |
| 진단 후 6개월 내 사망 | 관찰 창이 잘림 → **별도 지시자 변수 추가** + 민감도 분석에서 3개월 창 재실행 |

## 폐쇄망 입실 전 준비

`DIV_CD`(수가코드) 상세 목록은 카탈로그에 전부 수록되어 있지 않습니다.

- **1차 설계는 `CZ_ITEM_CD`(항목코드) 대분류** 기반으로 완성합니다. 이 값은 카탈로그에 명시되어 있습니다:
  `처치 및 수술` · `영상진단 및 방사선치료료` · `CT총액` · `MRI` · `검사료` · `주사료` · `투여료` · `입원료` · `마취료` · `완화의료 정액수가` · `특수장비` · `이학요법료` 등
- **2차로 `DIV_CD` 세부 코드**는 입실 후 실제 빈도 분포를 확인해 상위 코드부터 매핑합니다.
- 사전에 **보건의료빅데이터개방시스템(https://opendata.hira.or.kr)** 의 수가·일반명 코드표를 내려받아 매핑 사전을 만들어 두면 입실 후 시간을 크게 아낍니다. (카탈로그에도 이 사이트를 코드값 참조처로 안내하고 있습니다.)
