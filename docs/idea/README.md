# 추천 주제 — 청구데이터 기반 폐암 병기 추정 모델

> 작성일 2026-08-08 · 팀 구성 전제: **임상의 없음, 데이터/ML 중심**
> 대회 자료 원문·배점표는 [../competition/](../competition/) 참조

## 한 문장

> **폐암 병기조사 자료의 AJCC 8판 병기를 정답으로 삼아 건강보험 청구데이터만으로 진단 시 병기를 추정하는 모델을 개발·검증하고, 그 모델이 실제 연구에 쓸 수 있는지를 "소득계층 간 생존 격차" 재분석으로 입증한다.**

## 왜 이 주제인가 — 세 줄 요약

1. **정답 라벨이 이번 대회에서 처음 공개된다.** 국내 청구데이터에는 병기 정보가 없다는 점이 20년 가까이 지적돼 왔고([Kim 2017](07_참고문헌.md)), 이를 풀 수 있는 gold standard가 K-CURE 폐암 병기조사 DB(`HC_T_8TH`/`HC_N`/`HC_M_8TH`)로 제공된다. **이 대회가 아니면 할 수 없는 연구**다.
2. **해외에는 방법론 선례가 있고 국내에는 없다.** 미국 SEER-Medicare 기반 연구가 대장암 정확도 82.3%, NSCLC 77.5%를 보고했다([Finn 2023](07_참고문헌.md) 등). 검증된 설계를 한국 데이터에 이식하는 것이라 **실현 가능성이 높으면서 국내 최초**다.
3. **정부 계획과 직접 맞물린다.** 「제5차 암관리종합계획(2026~2030)」은 *"TNM 등 암등록변수 다양화 추진을 통해 정교한 암데이터 분석('27~)"* 을 과제로 명시했다. 이 모델은 그 과제를 데이터 측면에서 앞당기는 도구다.
