# 01. 대회 개요

## 공식 명칭

**제4차 임상 데이터 네트워크(K-CURE) 데이터 활용 경진대회**
(약칭: 제4차 K-CURE 데이터 경진대회)

> 3차까지는 "K-CURE **암 공공 라이브러리** 활용 경진대회"였으나, 4차부터 **임상 라이브러리가 추가 개방**되면서 명칭이 "K-CURE **데이터** 경진대회"로 확장되었습니다. 이 변화 자체가 4차의 핵심 메시지입니다.

## 주최 / 주관

- **주최**: 보건복지부
- **주관**: 한국보건의료정보원(KHIS), 국립암센터(NCC)
- **협력**: 건강보험심사평가원, 국민건강보험공단, 국가데이터처(구 통계청), 질병관리청 (데이터 제공기관)

## K-CURE란

**K-CURE** = **K**orea **C**linical data **U**tilization network for **R**esearch **E**xcellence

2022~2025년에 걸쳐 구축된 국가 암 연구 데이터 플랫폼. 두 개의 라이브러리로 구성됩니다.

```
K-CURE
├── 암 임상 라이브러리   ← 의료기관 EMR/CDW를 암종별로 표준화 (약 165만 명)
│                          위·유방·대장·간·췌장·폐·신장·혈액암·자궁경부·전립선암
└── 암 공공 라이브러리   ← 공공기관 암 관련 데이터 연계 (약 261만 명, 2012~2021 등록자)
                           암등록 + 자격/검진 + 청구 + 사망 + 코로나19
```

## 공고문에 명시된 목적 ⭐

> ① K-CURE 암 공공라이브러리 및 암 임상라이브러리 데이터 활용 활성화 및 **선도적 인공지능 기술 확대 확산**
> ② K-CURE 데이터 기반의 **우수모델 발굴**

**즉 4차는 AI·모델링을 명시적으로 요구합니다.** 순수 기술역학 연구는 목적 부합도에서 불리하므로, 예측/분류 모델 + 검증 설계를 포함시키는 것이 안전합니다.

## 4차 대회의 차별점 (= 심사에서 노려야 할 지점)

보도자료 인용: *"암 임상·공공 결합 데이터를 활용할 수 있는 **첫 기회**"*

1. **국립암센터 유방암 임상 라이브러리 + 암 공공 라이브러리 사전 결합 DB**가 처음 제공됨
   → 병원 안에서만 보이던 임상 상세(병기, 조직학적 소견, 치료 상세)와 병원 밖 이력(청구·검진·사망)이 한 환자에서 이어짐
2. **간암·폐암 병기 조사자료**로 구성된 공공 라이브러리 표본 DB 제공
   → 공공데이터의 최대 약점이던 "병기 정보 부재"가 일부 해소됨

**전략적 함의**: 심사위원은 "왜 하필 K-CURE여야 하는가"를 봅니다. 청구데이터만으로 되는 연구, 단일기관 EMR만으로 되는 연구는 약합니다. **결합이 있어야만 가능한 질문**을 던져야 합니다.

## 회차별 이력

| 회차 | 시기 | 제공 데이터 | 선정/수상 |
|---|---|---|---|
| 1차 | 2023 | 암 공공 라이브러리 표본DB (초기 암종) | 대상 보건복지부장관상 (상금 300만원 사례 확인) |
| 2차 | 2024.07~11 | 위·유방·간·대장암 표본DB (226만명 기반) | 10개 팀 선정 → 발표평가 |
| 3차 | 2025.06~11 | 6대 암종 표본DB (위·유방·대장·간·폐·췌장, 261만명) | 10개 팀 수상 (최우수상: 전북대병원 김현호 교수 연구팀) |
| **4차** | **2026.07~12** | **유방암 임상+공공 결합DB, 간암·폐암 병기조사 표본DB** | 15팀 선정 → **10팀 수상, 총 870만원** |

> 명칭 표기: 공고문 표지는 "제4**차**", 활용계획서 양식은 "제4**회**"로 되어 있습니다. 제출물에는 양식 표기를 그대로 두면 됩니다.

> 4차는 1차 통과 팀이 10 → **15팀으로 확대**되었습니다. 즉 서류 통과 문턱은 이전보다 낮아졌고, **발표평가에서 10/15가 수상**하므로 서류만 통과하면 수상 확률이 상당히 높습니다. → **1차 서류에 자원을 집중하는 것이 합리적**입니다.
