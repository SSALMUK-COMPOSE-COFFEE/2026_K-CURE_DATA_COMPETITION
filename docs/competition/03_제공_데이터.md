```
K-CURE
├── 암 임상 라이브러리   ← 의료기관 EMR/CDW를 암종별 표준화 (약 165만 명)
│                          위·유방·대장·간·췌장·폐·신장·혈액암·자궁경부·전립선암
```

## 결합의 실질적 가치 — 계획서에서 짚어야 할 지점

### 임상(또는 병기조사) 자료에만 있는 것
- 정확한 **TNM 병기** (폐암은 AJCC 8th 임상·병리 모두)
- **바이오마커** (폐암 EGFR/ALK, 유방암 ER/PR/HER2로 추정)
- **ECOG 전신상태**, 흡연력 (양·기간·금연연도)
- 종양표지자 (간암 AFP)

### 공공 자료에만 있는 것
- 병원 **밖**의 모든 의료이용 — 타 병원 전원, 요양병원, **응급실 도착경로**(`IPAT_ARIV_PTH_TP`)
- **사망 여부·일자·원인** → 병원 EMR의 추적 소실 편향 해소
- 진단 **이전**의 검진 이력·검사 수치·문진(흡연·음주·가족력)
- **보험료 분위**(1~10, 0=의료급여) = 사회경제적 계층
- 원외처방 총투여일수 → **실제 복약 순응도** 산출 가능

> 💡 결합의 핵심 가치는 변수 개수가 아니라 **"암 진단 전 검진 → 진단 시 병기·바이오마커 → 병원 안팎 치료 → 사망까지 한 사람의 궤적이 끊기지 않는다"** 는 점입니다.

## 데이터 관련 확인 필요 사항 (→ `data@ncc.re.kr`)

1. **유방암 임상×공공 결합DB의 데이터 카탈로그** (최우선)
2. 각 DB의 대상자 수 (간암/폐암 병기조사 N, 유방암 결합DB N)
3. 결측률 — 특히 폐암 `EGFR_MUTATION`, `ECOG`, 병리 병기(`HP_*`)
4. 표본DB(6대 암종)도 함께 제공되는지, 병기조사 DB와 별개인지
5. 대상자 단위 조인키의 구조 (청구는 `MID`, 대상자 간 연결키는?)
