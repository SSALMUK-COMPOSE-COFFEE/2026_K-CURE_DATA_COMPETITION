## 항목별 작성 가이드

### ① 주제
`[대상 데이터] 기반 [분석 대상]의 [예측/규명] 모델 개발 및 검증`
- 예: "폐암 병기조사 자료를 활용한 청구데이터 기반 임상병기 추정 모델 개발 및 검증"
- 예: "간암 검진 초음파·AFP 결과와 청구 이력을 결합한 조기 진단 예측 모델"

### ② 제안 배경 — 각주를 반드시 달 것

구성 4문단:
1. **질병 부담**: 국내 발생·사망 현황 (국가암등록통계 인용¹)
2. **현행 연구의 한계**: 선행연구를 인용하며 무엇이 안 되고 있는지²⁻⁴
3. **이 데이터로만 메울 수 있는 공백**: 병기조사 자료/결합DB가 왜 그 한계를 푸는지
4. **연구 질문**: 한 문장으로 명확하게

> 배점 문구가 "**참고문헌 대비** 필요성"이므로, 각주 없는 주장은 점수가 안 됩니다.

### ③ 데이터 전처리 — 실제 변수명을 쓸 것 (15점)

```
1) 사용 데이터셋
   - CS_LC_RGST (폐암 암등록, 32개 변수) : 진단 2014~2019년
   - CS_LC_T200 / T300 / T400 / T530 (청구, 2007~2023)
   - CS_LC_DEATH (사망, 2012~2022)
   - CS_LC_BFC (자격·보험료 분위)
2) 대상 기간 : 진단 2014~2019, 추적 ~2023
3) 코호트 정의 (단계별 예상 N 포함)
4) 변수 생성
   - 결과변수 : ...
   - 노출/특징변수 : MID로 T200-T300-T400 조인, GNL_CD 기반 약제 노출 …
   - 교란변수 : AGE, SEX, CALC_CTRB_VTILE_FD(보험료분위), CL_CD(요양기관종별)
5) 결측 처리 : 9(모름) 코드 처리 원칙, 다중대체 여부
```

→ 실제 변수명·코드값은 [09_데이터카탈로그_요약.md](09_데이터카탈로그_요약.md)와
`데이터카탈로그/` 폴더의 전체 텍스트에서 확인.

### ④ 분석 설계 — 소제목 3개로 쪼개서 배점을 각각 회수

```
4-1. 분석 방법 (구현 가능성 15점)
   - 사용 도구: R 4.x (survival, glmnet, ranger) / Python (scikit-learn, lifelines)
   - 모델: baseline 로지스틱/Cox → 정규화 회귀 → 트리 앙상블 비교
   - 데이터 규모와 처리 방식 (조인 전략, 메모리)

4-2. 기대 성과 (유의미한 성과 15점)
   - 예상 표본 N, 이벤트 수, 검정력
   - 1차 성과지표(primary endpoint) 정의

4-3. 결과 평가 및 검증 방법 (검증 15점) ⭐ 반드시 별도 소제목
   - 데이터 분할: train 70 / test 30, 또는 진단연도 기반 시간 분할 검증
   - 성능지표: AUROC, AUPRC, C-index, Brier score, calibration slope
   - 불확실성: 5-fold CV × 반복, 부트스트랩 95% CI
   - 해석성: SHAP / 변수 중요도, 임상 지식과의 정합성 확인
   - 민감도 분석: 코호트 정의 변경, 결측 처리 방식 변경
   - 통계 분석이면: 비례위험 가정 검정, 경쟁위험(Fine-Gray), E-value
```

### ⑤ 기대 효과 — 3요소 각 1단락 (20점)

```
1) 공익적 효과 : [국가암검진사업 / 암생존자 통합지지 / 호스피스·완화의료] 등
                 구체 사업명과 연결
2) 산업적 효과 : 의료 AI 제품화, 임상시험 대상자 선별, 심사·보장성 정책 근거
3) 확장 가능성 : 타 암종(위·대장·췌장) 확장, 전체 모집단 적용, 임상 라이브러리 결합
```

### ⑥ 참고 문헌
- 5~10건. 본문 각주 번호와 일치시킬 것
- 국가암등록통계, 관련 국내외 논문, 진료지침(NCCN 등) 혼합
