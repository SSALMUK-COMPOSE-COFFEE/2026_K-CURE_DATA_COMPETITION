# 04. 분석환경 및 제약

선정된 15개 팀은 **국립암센터 국가암데이터센터 / 의료데이터 안심활용센터**의 **폐쇄형 원격분석환경**에서 **2026.09.21(월) ~ 10.23(금)** 분석합니다. 이 환경의 제약이 연구 설계를 좌우하므로 계획서 단계에서 반드시 고려해야 합니다.

> ⚠️ 발표평가가 **10/27(화)** 입니다. 분석 종료 후 주말 포함 **4일**뿐이므로 발표자료는 분석 마지막 주에 병행 제작해야 합니다.

## 제공 소프트웨어

안심활용센터 공식 안내 기준:

| 도구 | 비고 |
|---|---|
| **SAS** | 명령어 기반 전문 통계 솔루션 (보건의료 빅데이터 표준) |
| **R / RStudio** | 오픈소스 통계 패키지 사용 가능 |
| **Python** | 데이터 사이언스 / 머신러닝 |
| **SPSS** | GUI 기반 통계 |
| **STATA** | 데이터 관리 + 시각화 + 통계 |

## 이용 시간

- **평일(월~금) 08:30 ~ 16:30**
- 공휴일·법정휴일 휴관

> ⚠️ **이것이 최대 제약입니다.** 9/21~10/23은 실근무일 **약 25일**, 하루 8시간이면 팀 전체에 **약 200시간**이 전부입니다(추석 등 공휴일 제외 시 더 짧음). 야간·주말 작업 불가. 직장인/전공의 팀은 실제 가용시간이 훨씬 적습니다.
> → 계획서의 분석 계획은 **이 시간 예산 안에서 끝나는 규모**여야 하고, 심사위원도 그걸 봅니다(실현 가능성 60점).

## 폐쇄망 제약 (중요)

| 제약 | 실무적 함의 |
|---|---|
| **인터넷 차단** | `pip install`, `install.packages()` 불가 가정. 필요한 패키지는 **사전 요청**해야 함 → 계획서/입실 전에 목록 제출 |
| **외부 데이터 반입 제한** | 외부 코호트, 공개 데이터셋 병합 연구는 사전 승인 필요 |
| **결과물 반출 심사** | 코드·표·그림만 심사 후 반출. **원자료·개인단위 데이터 반출 불가** |
| **소수 셀 억제** | 통상 셀 빈도 N<5(또는 기관 기준) 결과는 반출 불가 → **희귀 아형·소규모 하위군 분석은 결과를 못 가지고 나올 수 있음** |
| **LLM/외부 API 사용 불가** | 폐쇄망이므로 외부 AI API 호출 기반 방법론은 설계 불가 |
| **GPU 미확인** | 딥러닝 중심 설계는 위험. 사전 확인 필수 |

## 설계 시 지켜야 할 원칙

1. **하위군을 잘게 쪼개지 말 것** — 반출 심사에서 소수 셀이 잘려 결과가 누더기가 됨
2. **패키지 의존성을 최소화** — base R/SAS + 표준 패키지(survival, dplyr, tableone, ggplot2 / scikit-learn, pandas, lifelines)로 완결되게 설계
3. **입실 전 코드 완성** — 서류 발표(9/2)~분석 시작(9/21) 사이 3주에, 공개 유사 데이터(HIRA 표본자료, 건보공단 표본코호트)로 파이프라인을 미리 만들고 폐쇄망에는 **컬럼명만 바꿔 돌리는 상태**로 들어갈 것. 25일 안에 결과를 내는 유일한 방법
4. **해석 가능한 모델 + 엄밀한 검증** — 공고 목적은 "AI·우수모델 발굴"이지만 2차 배점 50%가 "과학적 원칙 부합"입니다. baseline(로지스틱/Cox) 대비 성능 비교 + SHAP 등 해석 + calibration을 함께 제시하는 구성이 양쪽을 모두 만족시킵니다. GPU가 필요한 대형 딥러닝은 사전 확인 없이는 위험
5. **결과물 산출을 앞당길 것** — 마지막 주는 반출 심사 + 발표자료(10/27)에 써야 함. 실질 분석기간은 4주
