|---|---|---|
| **필요성 (20점)** | 참고문헌 대비, 해당 분석의 필요성을 명확하게 제시 여부 | 20 |

| | 분석이 실제로 유의미한 성과 도출 가능 여부 | 15 |
| | **분석 결과를 평가하고 검증하는 방법론 제시 여부** | 15 |
| **기대효과 (20점)** | 공익적, 산업적 효과 및 향후 연구 확장 가능성 여부 | 20 |

## 배점표에서 도출되는 전략

### ⭐ 전략 1 — "실현 가능성 60점"이 승부처

동점 시 1순위도 실현 가능성입니다. 네 개 하위 항목을 **각각 별도 문단으로 명시적으로** 답해야 합니다.

| 하위 항목 (15점씩) | 계획서에서 반드시 할 것 |
|---|---|
| 데이터 카탈로그 내 변수 사용 | **실제 테이블명·컬럼명을 그대로 인용**. `CS_LC_RGST.HC_T_8TH`, `CS_LV_T530.GNL_CD` 처럼. → [09 문서](09_데이터카탈로그_요약.md) |
| 분석 방법 구현 가능 | 사용 도구(R/Python/SAS), 패키지, 데이터 규모 대비 처리 방식 명시 |
| 유의미한 성과 도출 | 예상 표본 수와 이벤트 수를 숫자로. 검정력이 나오는지 |
| **결과 평가·검증 방법론** | ⭐ **가장 많이 빠뜨리는 항목**. 아래 참조 |

**"검증 방법론" 문단은 반드시 넣으세요** — 이 15점만으로 순위가 갈립니다.
- 모델링이면: train/validation/test 분할 또는 k-fold CV, 성능지표(AUROC/AUPRC/C-index/Brier score), calibration plot, 외부·시간 분할 검증
- 역학 분석이면: 민감도 분석 목록, 비례위험 가정 검정, 결측 처리(다중대체) 및 그 타당성, E-value

### ⭐ 전략 2 — 공고문의 "AI·우수모델" 목적에 부합시켜라

공고문 목적: *"선도적 인공지능 기술 확대 확산"*, *"K-CURE 데이터 기반의 우수모델 발굴"*.

순수 기술역학 연구는 목적 부합도가 떨어집니다. 그렇다고 성능만 좇는 블랙박스도 "과학적 원칙 부합"(2차 50점)에서 불리합니다.

**권장 형태 = 예측/분류 모델 + 임상적 해석 + 엄밀한 검증**
- 예: "폐암 병기조사 자료를 정답 라벨로 하여 청구데이터 기반 병기 추정 모델 개발 및 검증"
- 예: "치료 전 변수로 EGFR 변이 양성 예측 / 생존 위험군 층화 모델 개발"
- 해석성 확보: SHAP, 변수 중요도, 로지스틱·Cox 대비 성능 비교(baseline 제시)

### 전략 3 — "필요성 20점"은 참고문헌으로 채점된다

배점 문구가 **"참고문헌 대비"** 필요성입니다. 즉 심사위원은 *선행연구를 인용해 공백(gap)을 보였는가*를 봅니다.
HWP 양식에도 `제안 배경` 항목에 "각 제안한 배경에 대해서 참고문서 증빙 / ex. 2023년 암환자발생은~~ 이다¹"라고 각주 형식이 지시되어 있습니다.

→ **문장마다 각주 번호를 달고, 참고 문헌 항목에 5~10건을 정리하세요.** 통계 인용은 국가암등록통계를 쓰면 됩니다.

### 전략 4 — 기대효과 20점 = 공익적 + 산업적 + 확장성 (3요소 모두)

배점 문구가 세 요소를 나열합니다. 세 개를 각각 한 단락씩 쓰세요.
- 공익적: 국가암검진·암생존자 관리·건강형평성 등 **특정 사업명**과 연결
- 산업적: 의료 AI 제품화, 임상시험 대상자 선별, 보험 심사 등
- 확장성: 타 암종·전체 모집단·임상 라이브러리로의 확장 경로

### 전략 5 — 확률 계산: 서류가 전부다

15팀 선정 → **10팀 수상 (67%)**. 서류만 통과하면 수상 확률이 매우 높습니다.
반대로 2차 배점의 50%가 "연구결과 중요성"이므로, **상위 시상(대상·최우수 3팀)을 노린다면 결과의 과학적 엄밀성**이 관건입니다.

### 전략 6 — 발표(2차) 대비 25점

- 10~15분 발표 + 5분 질의응답. **슬라이드 12~18장 수준**
- "주제가 분명하고 일관성 있게" — 한 문장 메시지를 정하고 모든 슬라이드가 그것을 지지하도록
- 질의응답 5분: 예상 질문(데이터 한계, 교란, 검증 방법) 답변을 미리 준비
