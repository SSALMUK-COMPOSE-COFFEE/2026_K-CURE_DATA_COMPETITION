## 🎯 이 대회의 성격 — 반드시 짚고 갈 것

공고문에 명시된 **목적**:
> ① K-CURE 암 공공/임상 라이브러리 데이터 활용 활성화 및 **선도적 인공지능 기술 확대·확산**

**즉 4차는 "AI/모델링"을 명시적으로 요구합니다.** 순수 역학 기술통계만으로는 목적 부합도가 떨어집니다. 다만 1차 배점의 60%가 *실현 가능성*(변수 사용·구현·성과·검증방법론)이므로, **검증 가능한 모델링 설계**가 정답입니다.
