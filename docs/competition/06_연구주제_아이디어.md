## A. 폐암 병기조사 DB (`CS_LC_*`) — 가장 강력한 트랙

폐암 암등록 테이블에 **EGFR/ALK 바이오마커 + ECOG + 흡연력 + AJCC 8th 임상·병리 TNM**이 들어 있습니다. 이 조합이 청구·사망과 결합된 국내 공개 데이터는 사실상 없습니다.

### ⭐ A-1. 청구데이터 기반 폐암 임상병기 추정 모델 개발·검증
`HC_T_8TH`/`HC_N`/`HC_M_8TH`를 **정답 라벨**로 삼고, 진단 전후 청구 패턴(`T300.DIV_CD` 수가코드, `T200.SOPR_YN` 수술여부, `T530.GNL_CD` 약제, 영상검사 코드)으로 병기를 추정.
- **왜 이번 대회에서만 가능한가**: 병기 정답 라벨이 이번에 처음 공개됨
- 모델: 다항 로지스틱 → gradient boosting, 검증: 진단연도 시간분할(2014~2017 train / 2018~2019 test), macro-AUROC·confusion matrix·calibration
- **기대효과**: 성공 시 병기 없는 모든 청구기반 암연구의 인프라가 됨 (산업적·확장성 만점)
- 필요성 ★★★ / 실현성 ★★★ / AI 부합 ★★★

### ⭐ A-2. 치료 전 변수 기반 EGFR 변이 양성 예측 모델
`EGFR_MUTATION`을 결과로, 임상변수(`SEX` `AGE` `SMOKE` `SMOKEDOSE` `SMOKEDUR` `H_NAME_2` 선암 여부 `ECOG`) + 진단 전 청구·검진(`G1E` 검사수치, `G1Q` 문진)으로 예측.
- 임상적 의의: 검사 미시행(`9`) 환자의 표적치료 후보군 선별
- 검증: 5-fold CV + calibration + SHAP 해석
- 필요성 ★★★ / 실현성 ★★★ / AI 부합 ★★★
- ⚠️ 주의: `EGFR_MUTATION=9`(미시행) 비율이 높을 수 있음 → 결측 처리 전략을 계획서에 명시

### A-3. 병기·바이오마커 보정 후 폐암 생존의 사회경제적 격차
동일 `HC_T/N/M`·`H_NAME_*`·`ECOG` 내에서 `BFC.CALC_CTRB_VTILE_FD`(보험료 분위)와 `SIDO_CD`(거주지)별 치료 강도(`SOPR_YN`, 항암 `GNL_CD`)와 생존(`DEATH.DREGDATE`) 차이.
- **핵심 신규성**: 기존 청구 연구가 못 하던 "병기 보정"이 가능해짐
- 방법: PSM/IPTW + Cox + Fine-Gray 경쟁위험, E-value
- 필요성 ★★★ / 실현성 ★★★ / 정책 임팩트 ★★★

### A-4. 폐암 진단 경로(응급실 vs 외래) 분류와 예후
`T200.IPAT_ARIV_PTH_TP`(입원 도착경로)와 진단 전 3~6개월 의료이용으로 진단 경로를 유형화하고, 경로별 병기 분포(`HC_*`)와 생존 비교.
- **응급실 도착경로 변수가 카탈로그에 실재**하므로 구현 가능
- 필요성 ★★★ / 실현성 ★★☆ / 정책 임팩트 ★★★

### A-5. 흡연력–조직형–바이오마커 궤적 군집화
`SMOKE`/`SMOKEDOSE`/`SMOKEDUR`/`SMOKEQUITYR` + `H_NAME_1~7` + `EGFR`/`ALK`로 환자 표현형(phenotype)을 비지도 군집화하고, 군집별 치료 패턴·생존 비교.
- 필요성 ★★ / 실현성 ★★★ / AI 부합 ★★★

## B. 간암 병기조사 DB (`CS_LV_*`)

간암 DB는 **국가 간암검진 결과 테이블(60~82개 변수)** 이 함께 제공되는 것이 최대 강점입니다.

### ⭐ B-1. 간암 검진 소견 기반 조기 진단·진행 예측 모델
`CS_LV_CLV_RST_0923`의 초음파 소견(`CLV_US*_DZ_FND`, 병변 위치 `CLV_US_CLV_LCTN_I~VIII`, 크기 `CLV_US_CLV_SIZE`), AFP(`CLV_AFP_QUAN_AMT`), 간염 상태(`CLV_HPTB_RST` `CLV_HPTC_RST`)로 진단 시 병기(`I_TNM_STAGE`)·생존을 예측.
- **검진 소견이 이 정도 세밀도로 공개된 사례가 없음** → 독창성 최상
- 필요성 ★★★ / 실현성 ★★★ / AI 부합 ★★★

### B-2. 간암 감시(surveillance) 수검 패턴과 진단 병기·생존
고위험군(B형·C형 간염, 간경변)에서 진단 전 검진 수검 이력(`CS_LV_CLV_RST_*`, `G1E`의 `SGOT`/`SGPT`/`GGT`) 밀도에 따라 진단 병기(`I_TNM_STAGE`)와 생존이 어떻게 달라지는가.
- 정책 직결: 국가 간암검진 6개월 주기 정책의 효과 평가
- 필요성 ★★★ / 실현성 ★★★ / 정책 임팩트 ★★★

### B-3. AFP 궤적과 예후 — 검진 AFP + 진단 시 AFP 결합
검진 AFP(`CLV_AFP_QUAN_AMT`, 반복 측정)와 진단 시 AFP(`RGST.AFP`)의 변화 궤적을 잠재계층성장모형(LCGA) 등으로 유형화하고 생존과 연결.
- 필요성 ★★★ / 실현성 ★★ / AI 부합 ★★

### B-4. 병기별 말기 의료이용 강도와 완화의료 진입
사망 전 30일 중환자실·항암 지속·응급실 방문(`T200` `T300`)을 `I_TNM_STAGE`별로 산출. `DGRSLT_TP_CD`(진료결과=사망)로 임종 장소 추정.
- 필요성 ★★★ / 실현성 ★★★ / 정책 임팩트 ★★★

## C. 유방암 임상×공공 결합DB (카탈로그 미확보 — 확인 후 결정)

카탈로그를 받기 전에는 변수 전제를 세울 수 없으므로 **`data@ncc.re.kr` 회신 전에는 이 트랙을 확정하지 마세요.** 유력 방향만 적어 둡니다.

- **C-1. 내분비요법 복약순응도(원외처방 `T530.TOT_INJC_DDCNT_EXEC_FQ` → PDC)와 재발·사망** — HR 상태를 임상 라이브러리에서 확보해야 성립
- **C-2. 아형·병기 보정 후 치료 이탈(타 기관 전원) 궤적과 생존**
- **C-3. 항암치료 후 심혈관 합병증** — 안트라사이클린/트라스투주맙 노출을 `GNL_CD`로 정의
